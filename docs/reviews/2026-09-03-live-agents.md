## 남은 것 (이번에 고치지 않음)

- **저장소 문서 자동 인덱싱**: `docs/DECISIONS.md` 에 이미 있는 규칙은 누군가 remember 하기 전엔 창고에 없다. 훅만으로는 첫 세션부터 경고가 뜨지 않는다 (Alice·Carol).
- **규칙 기반 증류의 한계**: LLM 미설정 환경에서는 제목이 질문 문장, 카테고리는 대부분 cases. `jv config set llm.provider …` 로 품질이 오른다는 안내는 있으나 기본 경험이 이것이다.
- **decisions 가 ⚠ 블록에 없음**: 위반 시 가장 위험한 것이 decisions 인데 시각적 우선순위가 pitfalls 보다 낮다 (Alice).
- **긍정 점수의 균등 강화**: `score 0.6` 이 팩 16건 전부를 올려 소음 항목도 함께 강해진다 (Carol).
- **ctx 만 반복 호출** 해도 "끝나지 않은 것"/"최근 작업"에 집계된다 (Bob).
- **오류 형식**: MCP 오류가 전부 200 + `isError` 텍스트, machine-readable code 없음 (Carol).
- `correction_similarity` 0.35 경계가 얇다 (진짜 교정 0.33~0.4 vs 이웃 사실 0.29~0.33).
