{{ icons.icon('compass') }} 연결 명령 — 에이전트 고르고 복사·붙여넣기만 하세요

아래 명령에 키가 이미 들어 있습니다. 에이전트 머신의 이 프로젝트 작업 폴더 터미널에 붙여 넣고 실행하면 끝입니다 (jv 설치가 아직이면 함께 설치됩니다).

자동 연결 (권장) Claude Code pi jcode MCP (Cursor·Codex)
{# ── 자동 ── #}

명령 하나가 jv 설치(없으면) + 연결 저장 + 이 머신에 깔린 모든 에이전트 (Claude Code·pi·jcode) 설치까지 처리합니다.

curl -fsSL {{ base }}/install.sh | bash -s -- --url {{ base }} --key {{ key }} --project {{ project.slug }}

실행 후: pi 는 재시작(또는 /reload) 후 연결할 세션에서 /myviking use, jcode 는 재시작, Claude Code 는 이 폴더에서 그대로 시작하면 됩니다.

{# ── Claude Code ── #}

Claude Code 전용. 세션 시작·질문·답변·변경까지 자동 캡처되는 완전한 연결입니다.

curl -fsSL {{ base }}/install.sh | bash -s -- --url {{ base }} --key {{ key }} --project {{ project.slug }}

또는 jv 가 이미 설치된 머신에서는: jv hook install --url {{ base }} --key {{ key }} --project {{ project.slug }}

{# ── pi ── #}

pi 전용. pi 세션은 기본 자유 사용 — 연결할 세션에서 /myviking use 로 이 프로젝트를 적용합니다 (다른 세션 영향 없음).

curl -fsSL {{ base }}/install.sh | bash -s -- --url {{ base }} --key {{ key }} --project {{ project.slug }}

실행 후 pi 재시작(또는 /reload) → 세션에서 /myviking use.

{# ── jcode ── #}

jcode(J-Code) 전용 — 훅·스킬·MCP가 설치되고 턴마다 자동 기록됩니다.

curl -fsSL {{ base }}/install.sh | bash -s -- --url {{ base }} --key {{ key }} --project {{ project.slug }}

실행 후 jcode 를 재시작하면 훅과 /myviking 스킬이 적용됩니다.

{# ── MCP ── #}

MCP 를 지원하는 에이전트(Cursor·Codex 등) — 설정 파일에 아래 JSON 을 붙여 넣으세요. (자동 캡처는 없고 도구 호출만 됩니다)

{
  "mcpServers": {
    "myviking": {
      "command": "jv",
      "args": ["mcp"],
      "env": {
        "MYVIKING_URL": "{{ base }}",
        "MYVIKING_KEY": "{{ key }}",
        "MYVIKING_PROJECT": "{{ project.slug }}"
      }
    }
  }
}
