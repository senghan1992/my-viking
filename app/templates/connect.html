⚡ 연결하는 3가지 방법

1. Claude Code (자동 캡처 — 권장)

에이전트 머신에서 한 번:

pip install git+https://github.com/senghan1992/my-viking.git

프로젝트 폴더에서 jv hook install 한 줄이면 세션 시작·질문·답변을 자동 기록합니다.

2. MCP (Cursor·Codex 등)

에이전트의 MCP 설정에 추가:

{
  "mcpServers": {
    "myviking": {
      "command": "jv",
      "args": ["mcp"],
      "env": {
        "MYVIKING_URL": "{{ base }}",
        "MYVIKING_KEY": "jv_...",
        "MYVIKING_PROJECT": "{{ project.slug }}"
      }
    }
  }
}

3. 셸 / 수동 (어떤 에이전트든)

jv brief -u {{ base }} -k jv_... -p {{ project.slug }}
jv search "배포 방법" -u {{ base }} -k jv_... -p {{ project.slug }}
jv remember "규칙" --content "내용" -u {{ base }} -k jv_... -p {{ project.slug }}

서버 주소 {{ base }} · 프로젝트 {{ project.slug }}

📜 에이전트 지침 (AGENTS.md 에 붙여넣기)

지식이 '확인된 사실'과 '검증 전'으로 나뉘어 주입됩니다. 검증 전은 단정하지 말고 확인하세요.

이 프로젝트는 myviking 지식 도서관에 연결되어 있습니다.
- 세션 시작 시 주입되는 브리핑과 질문마다 주입되는 '관련 지식'은 이전 작업의 축적입니다.
- ⟨검증 전⟩(fresh) 지식은 사실로 단정하지 말고 코드/문서로 확인하세요.
- 확립(established) 지식이라도 최근 결과와 어긋나면 "검증 필요" 경고로 표시됩니다.
- 새로 정한 규칙·함정·결정은 `jv remember "제목" --content "내용"` 또는 MCP 도구로 남기세요.
- 내 답변이 틀렸음을 알게 되면 같은 제목으로 바른 내용을 남겨 교정하세요.
