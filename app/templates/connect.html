{# ── Claude Code ── #}

세션 시작·질문·답변·변경 파일까지 자동으로 캡처되는 가장 완전한 연결입니다. 권장 구성이며, 아래 4단계를 한 번만 하면 됩니다.

1 에이전트 머신에 jv 설치

Claude Code 가 실행되는 컴퓨터의 터미널에서:

pip install git+https://github.com/senghan1992/my-viking.git

2 나의 프로젝트 폴더에서 연결

jv_... 자리에 방금 발급한 키를 붙여 넣으세요. 연결되면 서버 확인 메시지가 나옵니다.

jv hook install --url {{ base }} --key jv_... --project {{ project.slug }}

✓ 확인: 설치 후 jv hook check 를 실행하면 SessionStart 등 4개 이벤트가 설치되어 있다고 나옵니다.

3 Claude Code 로 작업 시작

이 폴더에서 평소처럼 Claude Code 를 쓰면 끝입니다. 자동으로 일어나는 일:

  • 세션 시작 → 지난 작업 브리핑 자동 주입
  • 질문마다 → 관련 지식만 골라 주입 (검증 전은 단정하지 않도록 표시)
  • 작업 종료 → 지식 자동 증류·기록, 틀린 지식은 '검증 필요'로 강등

4 확인

서가로 돌아가 보세요. 작업이 끝나면 지식 권이 자동으로 쌓여 있습니다.

{# ── pi ── #}

pi 전용 확장을 설치하면 세션 시작마다 브리핑이 자동으로 주입되고, 대화 중 viking_search·viking_remember 같은 도구를 에이전트가 직접 사용합니다.

1 jv 설치 (확장 생성기)

확장을 만들어 주는 jv CLI 를 한 번 설치합니다:

pip install git+https://github.com/senghan1992/my-viking.git

2 pi 확장 생성

jv_... 자리에 방금 발급한 키를 붙여 넣으세요. ~/.pi/agent/extensions/myviking.ts 파일이 만들어지고, 키가 들어 있어 소유자(0600)만 읽습니다.

jv pi install --url {{ base }} --key jv_... --project {{ project.slug }}

3 pi 재시작 또는 /reload

확장을 불러오려면 pi 를 껐다 켜거나, pi 안에서 /reload 를 입력하세요.

4 확인

새 세션을 열면 브리핑이 자동으로 주입됩니다. 작업 중에는 이렇게 쓰세요:

  • "지금까지 쌓인 지식 브리핑 줘" → viking_brief
  • "결제 재시도 관련 지식 검색해줘" → viking_search
  • "이 규칙을 기억해: 배포는 화요일만" → viking_remember

참고: pi 는 대화 기반이라 지식 자동 증류(commit)는 Claude Code 훅이 더 완전합니다. 중요 규칙·함정은 위 도구로 직접 남기면 됩니다.

{# ── MCP ── #}

MCP 를 지원하는 에이전트(Cursor·Codex 등)는 JSON 하나로 연결됩니다. 브리핑·검색·기록을 도구로 호출할 수 있지만, 세션 자동 캡처는 없습니다.

1 jv 설치

pip install git+https://github.com/senghan1992/my-viking.git

2 에이전트의 MCP 설정에 추가

설정 파일(예: Cursor → Settings → MCP, Codex → mcp.json)에 아래를 붙여 넣고 MYVIKING_KEY 에 방금 발급한 키를 넣으세요:

{
  "mcpServers": {
    "myviking": {
      "command": "jv",
      "args": ["mcp"],
      "env": {
        "MYVIKING_URL": "{{ base }}",
        "MYVIKING_KEY": "jv_...",
        "MYVIKING_PROJECT": "{{ project.slug }}"
      }
    }
  }
}

3 확인

에이전트에 "지식 브리핑 줘"라고 물어보면 viking_brief 도구가 동작합니다. 도구 목록: viking_brief · viking_search · viking_remember · viking_score

{# ── 셸 / 수동 ── #}

어떤 에이전트든 터미널 명령으로 도서관을 쓰는 방법입니다. 자동화는 없지만 가장 확실합니다.

1 jv 설치

pip install git+https://github.com/senghan1992/my-viking.git

2 자주 쓰는 명령

시작할 때 브리핑:

jv brief -u {{ base }} -k jv_... -p {{ project.slug }}

막혔을 때 검색:

jv search "배포 방법" -u {{ base }} -k jv_... -p {{ project.slug }}

알게 된 규칙 기록:

jv remember "릴리스는 화요일에만" --content "배포 동결은 월요일." -u {{ base }} -k jv_... -p {{ project.slug }}

3 팁

자주 쓰는 명령은 에이전트의 지침(AGENTS.md)에 넣어두거나 셸 별칭으로 만들어 두면 편합니다. jv --help 로 전체 명령을 볼 수 있습니다.

{{ icons.icon('copy') }} 에이전트 지침 (AGENTS.md 에 붙여넣기)

지식이 '확인된 사실'과 '검증 전'으로 나뉘어 주입됩니다. 검증 전은 단정하지 말고 확인하세요.

이 프로젝트는 myviking 지식 도서관에 연결되어 있습니다.
- 세션 시작 시 주입되는 브리핑과 질문마다 주입되는 '관련 지식'은 이전 작업의 축적입니다.
- ⟨검증 전⟩(fresh) 지식은 사실로 단정하지 말고 코드/문서로 확인하세요.
- 확립(established) 지식이라도 최근 결과와 어긋나면 "검증 필요" 경고로 표시됩니다.
- 새로 정한 규칙·함정·결정은 `jv remember "제목" --content "내용"` 또는 도구로 남기세요.
- 내 답변이 틀렸음을 알게 되면 같은 제목으로 바른 내용을 남겨 교정하세요.
