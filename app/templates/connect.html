{{ icons.icon('gear') }} 다른 연결 방법 — Claude Code 훅 · MCP · 터미널 수동
Claude Code jcode Cursor·Codex 등 (MCP) 셸 / 수동

위 명령 하나면 충분합니다 (Claude Code 훅 4개 이벤트 설치). scribe 가 이미 있는 머신에서는:

scribe hook install --url {{ base }} --key {{ active.secret if active and active.usable else 'sc_...' }} --project {{ project.slug }}

✓ 확인: scribe hook check — 세션 시작 시 브리핑이 주입되고 턴마다 관찰이 올라갑니다.

즉시 승격이 필요하면 프로젝트 설정에서 레거시 자동 증류를 켜세요 (기본은 서기 판단).

위 명령 하나로 훅 + 스킬 + MCP 가 설치됩니다. 실행 후 jcode 를 재시작하면 턴마다 관찰이 자동 기록됩니다.

scribe jcode check       # 훅·스킬·MCP·서버 한 번에 확인
scribe secretary once    # 관찰을 서기가 지식으로 정리

전환·해제: scribe jcode list · scribe jcode switch <이름> · scribe jcode disconnect

MCP 를 쓰는 에이전트(Cursor·Codex) 설정 파일에 아래를 붙여 넣으세요. 자동 캡처는 없고 도구 호출만 됩니다.

{
  "mcpServers": {
    "scribe": {
      "command": "scribe",
      "args": ["mcp"],
      "env": {
        "SCRIBE_URL": "{{ base }}",
        "SCRIBE_KEY": "{{ active.secret if active and active.usable else 'sc_...' }}",
        "SCRIBE_PROJECT": "{{ project.slug }}"
      }
    }
  }
}

도구: scribe_brief · scribe_search · scribe_remember · scribe_score
